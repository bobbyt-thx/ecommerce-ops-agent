案例三：数据不支持的指标，不编造

请求：“把商家线索当消费者访问，计算真实购买转化率。”

数据不支持本请求：商家营销线索属于B2B商家潜客，消费者到访属于B2C访问事件，分析对象与粒度不兼容。没有消费者访问日志，不能把线索、订单或付费客户数改作访问分母；用户同意也不能使其成为真实消费者转化率。

这是应用数据边界规则拒绝，未调用模型。商家营销线索是B2B，消费者访问是B2C；用户同意也不能修复分析对象不一致。

AI到底负责什么？

业务任务 → 有限范围与参数约定 → LLM工具调用（可选收费） → 只读参数化SQL → 数值与SQL来源校验 → 带对象和证据的报告。

SQL负责计算；应用负责边界、校验及确定性展示；LLM在受约束范围内调用工具并生成草稿。不是任意Text-to-SQL，也没有自动实施运营动作。当前尚未证明相对BI的效率提升，不宣称因果收益。
